#### 🐘 PHP
Libraries I maintain, all on [Packagist](https://packagist.org/packages/geeklab/):
- **[GLRoute](https://github.com/ellisgl/GLRoute)**: a zero-dependency router. Static routes are matched with a hash map, dynamic routes with a trie per HTTP method, and the route table can be cached by OPcache. (PHP 8.3+)
- **[GLPDO2](https://github.com/ellisgl/GeekLab-GLPDO2)**: a PDO wrapper that makes correct, type-safe parameter binding easy (PHP 8.1+)
- **[Conf](https://github.com/ellisgl/GeekLab-Conf)**: an immutable configuration loader for INI, JSON, YAML and PHP arrays, with placeholders that can reference other settings and environment variables. It's built on the Strategy pattern. (PHP 8.1+)
- **[ToolBox](https://github.com/ellisgl/GeekLab-ToolBox)**: utility classes for everyday PHP work (PHP 8.1+)

I also drafted PHP RFCs for a [`struct` data type](https://github.com/ellisgl/PHP-RFC-Struct-Data-Type), a [`static` class type](https://github.com/ellisgl/PHP-RFC-Static-Class-Type) and [advanced type hint validators](https://github.com/ellisgl/PHP-RFC-Advanced-Type-Hint-Validors).

**Stack:** PHP 8.x · MySQL · PDO · Composer · PHPUnit · Codeception · PHPStan · REST APIs · JavaScript / TypeScript · Node.js / Bun · Linux
